# Current Problems and Priority

## Critical

1. **MRJD parameter sweep remains unresolved.** Baseline code maps the plotted `E|J|/sigma` grid to jump means. Section 4 instead states `lambda/(beta+ - beta-)`, which is negative with the Table 2 ordering. Controlled alternatives were run, but none aligns the 12-date panel with its approximate multi-unit figure scale. No variant is selected merely because it looks closer.
2. **Randomized GradOne/GradTwo are reconstructed, not author-verified.** Production code now selects one of the `N(T)+1` realized intervals uniformly, weights the first-order term by `N(T)+1`, and weights selected-interval pair cross-differences by `(N(T)+1)/2`. This is unbiased relative to the exhaustive Taylor sums in expectation, and toy expectation tests pass. The paper gives exhaustive equations; the author's 2018 slides support the weighting clue but not enough implementation detail to establish identical estimator variance/distribution. [Author presentation](https://www.researchgate.net/publication/350193285_When_do_Jumps_Matter_in_Option_Prices).
3. **Inference under antithetic/stratified sampling is unresolved.** `t_statistic` uses path rows as iid with `n-1` degrees of freedom. Jump-time paths include randomized stratification of `N(T)>0` and complementary uniforms; Brownian increments are antithetic. The paper does not specify the effective independent unit or a dependence-aware standard error. This affects rejection and power.
4. **Saved figures are DEBUG outputs, not paper-scale results.** Four outer repetitions were run for both model pairs; Figure 2 rejection estimates can only be multiples of 0.25. The 500/300 experiment has not run. The paper-mode gate is intentionally closed while method and numerical discrepancies remain.
5. **Figure 1 is not numerically reproduced.** Current maxima are 0.052110, 0.166304, 0.493713, and 0.463548 for panels (a)-(d), versus approximate source-image reads near 0.058, 1.2, 0.38, and 5.8. These source readings are visual approximations, not published numeric points.

## High

6. Jump marks are now sampled independently across paths; the unsupported antithetic mark pairing has been removed. Brownian and jump-time antithetic constructions remain and are documented.
7. A `mix_transition_samples` helper now handles the `p_theta=(1-theta)p+theta q` endpoints, with exact theta=0/1 and argument validation tests. There is not yet a complete distributional transition-kernel validation for all models.
8. Six analytical output checks pass: GBM call/Black-Scholes, Merton call/Poisson mixture, Vasicek mean and variance, and compensated MRJD mean and variance. These do not validate randomized MVD variance, t-test calibration, or published curves.
9. Figure layouts are functional reconstructions, not typographic/layout replicas. The source paper publishes plots but not underlying curve points; the comparison table only uses cautious visual readings for four panel extrema.
10. Optional per-path persistence of realized partitions, marks, local effects and CRN inputs is absent. Current diagnostics include aggregate jump-count strata but not a full path trace.
11. Parameter/result outputs are CSV, not parallel JSON/TeX exports. No paper numerical result tables are claimed because the article does not publish the curve arrays as tables.

## Reproducibility Limits

12. No `.git` directory or source ZIP is present in this checkout, so the original archive and commit cannot be recovered. The latest pipeline run nevertheless records source/config/paper/output SHA-256 hashes in `reproduction/reproducibility_manifest.json`, plus OS, CPU, packages, seed and timing.
13. The root-level `figure1_median_power.pdf` is an orphaned Matplotlib document and is not generated by the current pipeline.

## Must Not Claim

The project is a validated reconstruction foundation, **not an exact or completed A-to-Z replication**. Do not present the current DEBUG figures as paper-scale outputs or claim author-identical gradient-statistic distributions.
